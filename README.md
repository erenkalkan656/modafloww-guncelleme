# ModaFloww Panel güncellemeleri

Bu depo yalnızca ModaFloww Panel Android uygulamasının uygulama içi güncellemeleri içindir.
Uygulama `latest.json` dosyasını okur, yeni sürüm varsa APK'yı indirir, SHA-256 özetini doğrular ve kurulumu sizin onayınızla başlatır.
Bu depoda kaynak kod, şifre veya anahtar yoktur.
